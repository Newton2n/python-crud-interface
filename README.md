# Python CRUD Interface

A simple example of implementing an interface in Python using Abstract Base Classes (ABC).

### What is an Interface?

An interface defines a set of methods that a class must implement. It provides a common structure while allowing each class to define its own implementation.

### Implementation

Python doesn't have a dedicated `interface` keyword. We can achieve similar behavior using `ABC` and `@abstractmethod`.

This project demonstrates a simple CRUD interface and its implementation using a `User` class.

### Concepts
- Abstract Base Class (ABC)
- Abstract Methods
- Inheritance
- Method Overriding

### Run

python main.py
